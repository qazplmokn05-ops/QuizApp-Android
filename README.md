# QuizApp Android

Упрощённая Android-версия квиза на Kotlin/Jetpack Compose.

Что внутри:
- стартовый экран с именем игрока
- игровой экран с вопросами и таймером
- подсветка правильного/неправильного ответа
- финальный экран со счётом

Как запустить:
1. Откройте проект в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на эмуляторе или телефоне.

Сборка тестировалась как базовая структура проекта, но для полной сборки нужно, чтобы Android Studio загрузил зависимости Gradle.
